# PRE Juveniles CDL — versión web

Esta rama (`gh-pages`) es la **versión web** de la app, publicada con GitHub Pages:
https://oscaralejandrojuarezleal-beep.github.io/pre-juveniles-apk/

- Es la **misma app** que la APK: la baja completa desde Apps Script (`PRE_apiAppApk`) y la guarda en el navegador.
- La primera vez tarda unos segundos; después abre al instante (también sin internet).
- Cuando hay versión nueva, la app avisa sola ("Nueva versión disponible") y "Actualizar ahora" la baja acá mismo.
- Se puede instalar en la PC o el celular como app (ícono, pantalla completa, sin el cartel de Google).
- Los datos siguen en Apps Script. El link de Apps Script sigue funcionando igual.

Esta rama no toca la APK: la APK se compila sólo desde `main`.
